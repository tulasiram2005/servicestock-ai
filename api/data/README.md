# Demand source

carparts.json is a downloaded cache of Monash's car-parts dataset, distributed
through Zenodo record 4656021. Its provenance includes the ZIP SHA256 and source URL.
The upstream no-missing-values variant replaces missing observations with zero.
This demo uses the first 24 series, not the whole dataset. All associated costs,
lead times, criticality, descriptions, suppliers and configuration data are synthetic.
